# Проверки Control Groups 1.1.0 — задание V2

Дата: **17 ноября 2026**. Ветка: `feature/control-groups`. Цель: **Mindustry v160.7**, **Arc 7445105cd2**. Компиляция: Java 17.0.15, Gradle Wrapper 8.12.1.

Исходная контрольная точка сохранена в [VALIDATION_V1.md](VALIDATION_V1.md). Требования: [SPEC_V2.txt](SPEC_V2.txt); решения: [V2_DECISIONS.md](V2_DECISIONS.md); общий поток данных: [ARCHITECTURE.md](ARCHITECTURE.md).

## Реализация и сверка требований

- Один переключатель сокрытия с независимыми сохранёнными значениями: командование — включено, строительство — выключено. Старое значение мигрирует только в командование.
- Три системы распределения длины и три правила нераспределённых. Внутренние проекции резервируются до распределения и вычитаются один раз. Остаточный минимум нераспределённых защищается с пределом длина/3; введённое число сохраняется отдельно от эффективного предела.
- Внешние проекции размещаются только поперёк, внутренние — вдоль хотбара. Квадратный минимум растёт к центру, без изменения редактируемой рамки или коэффициента изображения. Ручной largest меняет вписывание, сохраняя геометрию резерва; максимум проекции удалён.
- Независимые размер иконок (36), влияние hitSize (20%), отступ счётчика (2), показ единицы по умолчанию и более подробные иконки при достаточном физическом размере. Учитывается фактически сжатая иконка, а не только желаемый размер.
- Бан по стабильному имени: автоматические признаки и все CoreBlock.unitType, пользовательское переопределение, все типы в таблице. Забаненные исключаются из составов, состояний, представителей, выбора, нераспределённых и largest. Реестр, свойства типов и ванильные сохранённые группы не меняются.
- Разделы/подразделы редактора, общие поля со сбросом, подписи на половине строки, перенос совмещённого поля в узком окне. Читаемые поля типов, цветной HEX, отдельная колонка бана. Tooltip без фона, светло-серые, ограничены шириной редактора.
- Стандартный фон Tex.pane сохраняется; состояние окрашивает только существующий бордюр. Рамки редактора растут внутрь, активные грани выделены жёлтым. Разделитель внутри проекции. Панель инструментов не поворачивается вместе с хотбаром.
- HUD работает в строительстве. Клик выбирает и включает штатное командование, прекращает активный предпросмотр блока без изменения очереди. Редактор удерживает фокус и контекст при штатном сбросе commandMode текстовым полем.
- Телеметрия по умолчанию закрыта. В закрытом/скрытом состоянии не работают диагностические таймеры, счётчики и форматирование. Рабочие обновления продолжаются. Правки чистой геометрии не запускают дополнительный сбор игровых данных.

Все доступные требования V2 реализованы. Физически невозможные размеры и штатный удерживаемый режим трактуются явно в разделе ограничений ниже.

## Заключительная проверка архитектуры

Сбор составов/классификация остаётся единственным GroupModel. Кнопки, настройки и проекции не добавляют своих сборщиков юнитов. Метаданные, составы, геометрия и рисование обновляются отдельно; переходы состояний/смена представителя не инициируют разметку.

Резерв R считается до распределения S, полный размер равен S+R. Квадратная добавка и ручной largest не возвращаются в этот расчёт циклом. Позиции ячеек, строки счётчиков и UV переиспользуются. Новые GL-текстуры и игровые копии не создаются в кадровом пути. Индекс бана обновляется в save на игровом потоке.

Стили копируются локально; обработчики глобального ввода не добавлены. Родной commandMode/выбор/камера используются с проверкой команды, валидности, playerControllable, isCommandable и allowCommand. При сбросе мира освобождаются наблюдения/проекции/выбор и фокус редактора; телеметрия выключается. Существенного дублирования подсистем при заключительной сверке не найдено.

## Технические трактовки и оставшиеся игровые проверки

1. **Нехватка экрана:** если квадрат физически не помещается, он ограничивается экраном; если не помещаются минимумы всех кнопок, уменьшаются минимумы, с приоритетом остаточного минимума нераспределённых. Отрицательных размеров и продольного выхода нет. Это согласование несовместимых физических ограничений.
2. **Удерживаемое командование:** выбор включает штатный commandMode, но дальнейшая длительность следует настройке commandmodehold. При удерживаемом режиме требуется штатная клавиша, выбор сохраняется. Мод не меняет предпочтение, привязки и не имитирует удерживаемые клавиши. Контекст редактора фиксируется на время редактирования, чтобы фокус поля не переключал адресуемое сокрытие.
3. **Проекции:** алгоритм «Полноценной проекции» сохранён. База — корпус/оружие/позы/гусеницы/индикация состояния; расширение — поддерживаемые двигатели, heat, shield и RegionPart. Мировые частицы/свет/произвольный сторонний рендер не воспроизводятся. Точный перечень — [STATES_AND_PROJECTIONS.md](STATES_AND_PROJECTIONS.md).
4. **Совместимость:** совместная загрузка и ввод при установленном BuildWheel проверены. Ручные сочетания его колёс/изменённых привязок, произвольные сторонние UnitType/AI, бой и мультиплеер остаются для дополнительной игровой проверки. Пользовательские файлы BuildWheel не редактировались.
5. **Платформы:** собран настольный Java JAR; Android DEX не создавался. Все варианты масштаба/драйверов/GPU и длительная игровая нагрузка не проверялись. Успешные тесты и компиляция не обещают универсальной совместимости.
